# Active Coronagraph

This documentation is a starting point for publication. The package code lives
under `src/active_coronagraph`, examples under `examples`, tests under `tests`,
and runtime data under `data`.

## User Documentation

- [Quick User Instructions](quick_user_instructions.md): simple mask list,
  main functions, and copy-paste Python examples for running simulations.
- [Full User Guide](user_guide.md): installation, verification, first simulation,
  Python API, configuration, mask types, phase masks, sampling, wavelength,
  supplied data, phase screens, outputs, and CLI workflows.

## Configuration

- `ACTIVE_CORONAGRAPH_DATA_DIR`: runtime FITS/PNG data directory.
- `ACTIVE_CORONAGRAPH_OUTPUT_DIR`: generated simulation output directory.
